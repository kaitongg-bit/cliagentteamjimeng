# SOP 实验计划：从剧本到招募、分镜、素材、视频生成

## 目标

老板的问题不是“剧本 agent team 是否有效”这一件事，而是：

> 剧本测完后，能否按照 AI 视频生产 SOP，继续验证 agent team 在招募/素材挖掘、分镜、素材生成、视频生成这些节点上是否真的提升产物质量。

本实验计划只围绕《流量寄生虫》继续跑，避免换题导致变量太多。

## 核心假设

1. 剧本阶段的 agent team 价值主要体现在结构、逻辑、主题、可拍性。
2. 招募/素材挖掘阶段的 agent team 价值主要体现在“盘点完整、引用准确、减少漏项、降低后续生成返工”。
3. 分镜阶段的 agent team 价值主要体现在“把剧本切成可生成的视频 clip，而不是文学分镜”。
4. 视频提示词阶段的 agent team 价值主要体现在“符合工具生成单位、控制屏幕/多人/手部/文字等 AIGC 翻车点”。

## 依赖矩阵

每个节点开始前，Showrunner 必须自检前置依赖是否完成。未完成则倒回补齐，禁止跳步。

| 节点 | 前置依赖 | 不满足时的动作 | 主要交付物 |
|---|---|---|---|
| 1. 创意发散 | Human 输入 | 请 Human 补 brief | 概念方向、故事种子 |
| 2. 剧本 | 创意方向或用户已有梗概 | 先补 10 分钟剧情结构 | 剧本/剧情梗概/场次版 |
| 3. 招募/素材挖掘 | 剧本完成，或用户上传素材 | 从剧本盘点人物、场地、道具、风格参考需求 | 角色表、场景表、道具表、参考图搜索清单 |
| 4. 分镜表 | 剧本完成 | 先补 script chunk | 上游 6 列分镜表 |
| 5. 素材生成 | 素材挖掘 + 素材引用 | 先补 moodboard / 引用表 | 人物白底设定、场景图、关键道具图 |
| 6. 视频生成 | AI 脚本 + 素材确认 | 两者缺一不可，缺则倒回 | clip 表、即梦/Seedance 视频提示词 |
| 7. 剪辑成片 | 视频生成完成 | 不在本轮实验内 | 粗剪版本、问题清单 |

注：截图里“招募”这里按“素材挖掘/ casting breakdown”理解，不是招真人演员，而是从剧本中盘点演员、场地、道具、视觉参考和可复用素材。

## 最小角色配置

为避免 agent 太多烧 token，每个节点最多启用 2-3 个子 agent，加一个 Showrunner。

### 固定角色

| 角色 | 何时使用 | 责任 |
|---|---|---|
| Showrunner | 全程 | 自检依赖、决定是否进入下一节点、合并冲突意见 |
| Human | 每个关键准入点 | 选择方向、确认素材、判断审美是否对 |

### 节点角色

| 节点 | 子 agent | 为什么需要 |
|---|---|---|
| 招募/素材挖掘 | 素材挖掘 agent + 连续性/制片 agent | 从剧本抽取演员/场地/道具/可复用素材，检查是否漏项 |
| 分镜表 | 导演/分镜 agent + 剪辑/声音 agent | 把剧本切成 10-15 秒可生成 clip，并补声音/节奏 |
| 素材生成 | 美术概念 agent + 提示词结构 agent | 生人物/场景/道具参考图，控制风格和提示词结构 |
| 视频生成 | 提示词结构 agent + 生成风险审查 agent | 生成即梦视频提示词，并检查屏幕、手、多人、文字等风险 |
| 对照组 | single agent baseline | 干净上下文同题输出，用于对比 agent team 增益 |

暂不启用：观众、反方编剧、审片人。  
原因：这轮重点不是重新评剧本，而是测试生产 SOP。只有当片段产物出现“看不懂/短剧/主题跑偏”时，再临时启用观众或审片人。

## 实验设计

### 实验 A：招募/素材挖掘节点

范围：基于《流量寄生虫》已完成的 `0:00-6:00` 剧本/提示词产物。

输入：

- `traffic_parasite_revised_outline_v1.md`
- `first3min_jimeng_video_prompts_v4.md`
- `second3min_jimeng_video_prompts_v2.md`

agent team 流程：

1. 素材挖掘 agent 从剧本和前 6 分钟提示词里抽取：
   - 角色：沈砚、张总、助理、运营、公关、法务、品牌方、摄影师、服务生。
   - 场地：电影奖舞台、后台侧廊、高层酒店庆功宴、服务通道、临时公关房间。
   - 道具：奖杯、手机、平板、笔记本电脑、文件夹、香槟杯、打印机、清洁车、备餐架。
   - 风格参考需求：正式电影奖内场、酒店后场、危机公关会议室、冷暖光对照。
2. 连续性/制片 agent 检查：
   - 哪些素材可复用；
   - 哪些需要新生成；
   - 哪些不应该生成可读文字；
   - 哪些会导致即梦失败。
3. Showrunner 合并成“素材招募表”。

single agent baseline：

- 干净上下文，只给同样输入，要求一次性输出素材招募表。

交付物：

- `recruitment_material_breakdown_agent_team.md`
- `recruitment_material_breakdown_single_agent.md`
- `recruitment_material_breakdown_comparison.md`

评分维度：

| 维度 | 说明 |
|---|---|
| 完整性 | 是否漏掉关键演员、场地、道具、屏幕类素材 |
| 可复用性 | 是否识别哪些素材跨 clip 复用 |
| 生成风险意识 | 是否标注可读文字、手部、多人、屏幕风险 |
| Human 可用性 | 用户能不能直接照着找参考图/上传素材 |
| 后续依赖价值 | 是否能直接喂给分镜和素材生成节点 |

### 实验 B：下一个 3 分钟片段

范围：`6:00-9:00`。  
目标：继续推进“黑料开始外化，但不做全网骂声快剪”，测试 agent team 在下一片段的稳定性。

推荐剧情方向：

- 沈砚被带离庆功宴；
- 公司车/地下停车场/酒店后门；
- 他第一次看到被剪裁的监控、录音、聊天截图碎片；
- 张总要求他发低姿态回应；
- 他拒绝，但手机和账号已不在自己手里；
- 片尾钩子：品牌/平台/媒体电话陆续进来，但还不进入第二天全网崩塌。

启用角色：

1. 编剧/连续性 agent：只定 `6:00-9:00` beat，确保不跳到后面剧情。
2. 导演/分镜 agent：输出 12 个 15 秒段落。
3. 提示词结构 + 生成风险 agent：压成即梦视频提示词，并做审查。

交付物：

- `third3min_showrunner_synthesis_v1.md`
- `third3min_jimeng_video_prompts_v1.md`
- `third3min_prompt_review.md`
- `third3min_jimeng_video_prompts_v2.md`

对照组：

- `third3min_single_agent_baseline.md`

评分重点：

- 是否继续保持“流程恐怖”，而不是变成热搜狗血。
- 是否和 0:00-6:00 的人物、空间、手机/账号接管连续。
- 是否每条提示词都能直接给即梦生成。
- 是否减少可读文字、屏幕、手部、多人群像的失败概率。

### 实验 C：素材生成小样

范围：不全量生成，只做最小可验证素材包。

选择 5 个高价值素材：

1. 沈砚人物三视图/白底设定。
2. 张总人物三视图/白底设定。
3. 高层酒店庆功宴空间参考。
4. 冷白服务通道空间参考。
5. 临时公关房间空间参考。

启用角色：

- 美术概念 agent：定义画面质感、参考片方向、不要只写道具。
- 提示词结构 agent：输出短、清楚、可投喂即梦的图片提示词。
- Human：确认“像不像心里那部片”，不确认则不进入视频生成。

交付物：

- `visual_asset_prompt_pack_v1.md`
- 即梦生成图或外部参考图索引
- `asset_confirmation_report.md`

评分重点：

- 人物是否能跨 clip 保持一致；
- 场景是否符合电影级真实感；
- 是否避免“AI 精致假”“短剧豪华”“屏幕文字错误”；
- Human 是否能明确说出要/不要。

### 实验 D：视频生成小样

范围：只取 5 条推荐 clip 试生成，不全量 9 分钟。

从当前 `3:00-6:00` v2 先选：

1. `01 3:00-3:15`：庆功仍在、手机已离身。
2. `07 4:30-4:45`：服务通道真实感。
3. `08 4:45-5:00`：权限交接是否翻车。
4. `10 5:15-5:30`：手机够不到的权力关系。
5. `12 5:45-6:00`：冷白房间与暖金庆功宴对照。

启用角色：

- 提示词结构 agent：根据实际生成结果改 prompt。
- 生成风险审查 agent：判断失败是模型能力、素材不足，还是提示词问题。
- Human：选择哪条继续迭代。

交付物：

- 每条 clip 的提示词、素材引用、生成结果路径。
- `video_generation_test_report.md`
- `prompt_revision_notes.md`

评分重点：

| 维度 | 说明 |
|---|---|
| 画面真实感 | 是否像电影，而非短剧/广告/综艺 |
| 动作可读性 | 观众是否能看懂“手机离身/权限交接/解释权丢失” |
| 生成稳定性 | 人脸、手、屏幕、文字是否崩 |
| 连续性 | 沈砚、张总、空间、光线是否延续 |
| 可剪辑性 | 15 秒内部是否有起承转合 |

## 每轮实验固定输出格式

每个实验节点都按同样结构输出，方便老板横向看：

```text
01_input/
  输入文件和用户确认

02_agent_team/
  子 agent 原始产物
  showrunner synthesis
  final deliverable

03_single_agent_baseline/
  干净上下文 baseline

04_comparison/
  评分表
  agent team 增益
  成本/时间/token 备注

05_next_action/
  是否进入下一节点
  如果不进入，缺哪个依赖
```

## 成功标准

不是“agent team 每次都赢”，而是要能回答：

1. 哪些节点 single agent 足够好，可以不用 agent team？
2. 哪些节点必须引入少量角色才能显著减少返工？
3. 哪些角色最有性价比？
4. Human 应该在哪些准入点介入？
5. 哪些产物可以产品化成固定入口？

初步预期：

- 剧本：编剧 + 反方/观众/导演价值高。
- 招募/素材挖掘：素材挖掘 + 连续性/制片价值高。
- 分镜/视频提示词：导演/分镜 + 提示词结构 + 生成风险审查价值高。
- 素材审美：美术概念 + Human 价值高。
- 全程不建议堆很多 agent，Showrunner 必须负责收敛。

## 下一步建议

立刻执行实验 A：招募/素材挖掘。

原因：

1. 截图 SOP 明确要求剧本完成后启动招募/素材挖掘。
2. 我们已经有 `0:00-6:00` 的剧本化视频提示词，足够盘点演员、场地、道具。
3. 这个节点能直接检验 agent team 是否减少后续素材生成和视频生成返工。

实验 A 完成后，再进入实验 B：`6:00-9:00` 下一片段。
