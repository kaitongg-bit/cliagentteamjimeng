# 素材短表迭代结果：v3 到 v4

## 为什么继续改

v3 已经比早期长表更干净，但仍然有两个问题：

1. 默认 reviewer 还是太偏“创作讨论”，不够贴近即梦生成和分镜落地。
2. 主持人、礼仪、摄影区、媒体记者、庆功宴社交人群、服务生/后勤这类功能人物和功能人群被压得过轻，导致短表不够完整。

## 这次怎么改

reviewer 角色切换为：

- 提示词可执行 reviewer：检查素材短表能否直接支撑即梦生成与下游提示词。
- 导演/分镜 reviewer：检查功能人物、场景可信度和镜头调度是否成立。

不再把编剧 reviewer、美术概念 reviewer 作为素材挖掘节点默认 reviewer。

## v4 相比 v3 的提升

| 维度 | v3 | v4 |
|---|---|---|
| 颁奖礼成立感 | 主持人、礼仪缺位 | 补回颁奖流程人物 |
| 行业现场可信度 | 摄影区与记者太弱 | 补回摄影区与媒体记者 |
| 庆功宴场面 | 只有张总、沈砚和抽象人群 | 补回庆功宴社交人群 |
| 后台空间真实感 | 服务通道偏空 | 明确保留服务生与后勤作为场景元素 |
| 执行系统可读性 | 执行人员分类过粗 | 助理、运营、公关、法务四个功能位分清 |
| 资产边界 | 一些规则仍偏抽象 | 更明确哪些是人物、场景、物品，哪些只进镜头提示词 |

## 当前判断

v4 比 v3 更接近“完整、合理、能直接往即梦和分镜走”的版本。

它没有重新膨胀成场务全清单，但保留了那些虽然出现少、却会决定世界是否成立的功能人物和功能人群。
