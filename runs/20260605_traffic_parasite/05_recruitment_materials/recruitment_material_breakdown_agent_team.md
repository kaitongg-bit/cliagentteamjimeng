# 《流量寄生虫》0:00-6:00 最终素材招募表 agent team

## 1. 范围与准入

本轮只覆盖 `0:00-6:00`：

- 颁奖礼内场；
- 舞台到后台；
- 高层酒店庆功宴；
- 手机离身与账号接管；
- 服务通道；
- 临时公关房间；
- 低姿态回应被准备，但沈砚尚未认可。

前 6 分钟不展示具体黑料证据，不招募热搜大字、聊天截图、酒店监控图、变声录音细节。这里只拍“异动抵达公司流程”，不拍“全网审判”。

## 2. 视觉世界硬规则

所有空间都体面，但都露出后台系统。  
所有金属和玻璃都反光，但不广告化。  
所有屏幕都发光，但不提供信息。

统一视觉母题：

| 母题 | 用途 |
|---|---|
| 冷白追光 | 颁奖荣耀，但已经带有切割感 |
| 深色木饰面 | 正式电影奖内场，不是综艺舞台 |
| 灰色地胶/防撞条 | 后台系统和服务通道的真实材质 |
| 金属窄边/不锈钢 | 奖杯、备餐架、腕表、文件夹边缘 |
| 玻璃反射 | 资本空间和公关房间的隔离感 |
| 冷白屏幕光 | 手机/电脑只作为权力和流程，不作为信息板 |
| 暖金庆功灯 | 外部庆祝仍在继续，和内部冷白处理形成对照 |

## 3. 角色/演员资产

| 角色 | 叙事功能 | 视觉锁定 | 动作资产 | 优先级 | 白底/三视图 |
|---|---|---|---|---|---|
| 沈砚 | 被祝贺的人变成待处理对象 | 35岁左右，偏长窄脸，清晰颧骨，窄双或单眼皮，眼尾细纹；黑色短发后梳但不油亮；深午夜蓝近黑礼服，黑色缎面窄驳领，极小银色窄叶形胸针 | 握奖杯、职业微笑、摸空口袋、伸手要手机、手停在半空、推回文件夹、低声“我没有” | P0 | 需要三视图、礼服全身、半身、手部动作 |

| 服务生/清洁人员 | 后场真实感 | 酒店后场制服 | 贴墙让路、推清洁车 | P2 | 不需要 |
| 场外粉丝群像 | 公众爱意只在屏幕里 | 围栏、手机灯光、压缩直播画面 | 远声喊名，只在监看屏/直播屏出现 | P1 | 不需要 |

## 4. 必须一眼看懂的故事资产

这些素材不是装饰，必须在后续图像/分镜/视频里被观众一眼读懂：

| 故事资产 | 表达方式 | 不能误读成 |
|---|---|---|
| 沈砚手机不在自己手里 | 助理/运营拿着他的手机，他摸口袋为空 | 他忘带手机 |
| 屏幕背向沈砚 | 手机冷光和滑动动作可见，但他看不到内容 | 普通工作协助 |
| 运营替账号发声 | 沈砚伸手又放下，运营收回手机 | 普通发物料 |
| 张总职业化接管 | 挡酒、扶背、拿杯、压文件、推文件 | 反派威胁或霸总 |
| 服务通道转场 | 冷白荧光、灰地胶、防撞条、清洁车、备餐架 | 豪华酒店走廊 |
| 权限交接 | 法务/备用手机/笔记本/手机被拿走 | 黑客操作 |
| 低姿态回应不是道歉 | 纸张灰段落、签字空白；沈砚不认可 | 正式道歉已发布 |
| 外面庆功继续 | 玻璃外暖金举杯，里面冷白会议 | 全场已经知道塌房 |

## 9. 素材优先级

P0 必须先锁定：

- 沈砚白底三视图 + 礼服 + 胸针 + 手机；
- 张总白底三视图 + 腕表 + 手部动作；
- 助理/运营/公关/法务四类职业角色视觉区分；
- 高层酒店庆功区；
- 酒店服务通道；
- 临时公关房间；
- 虚构金色奖杯 + 泡棉保护箱；
- 屏幕/文字后期资产包；
- 关键动作资产包。

P1 可并行：

- 正式电影奖内场与摄影区；
- 剧院后台侧廊；
- 主持人、礼仪、行业观众、媒体记者；

- 庆功宴摄影师/合影执行人员；
- 香槟杯、文件夹、合同灰段落、打印机、相机；

P2 可后补：

- 服务生/清洁人员；
- 花篮、航空箱细节；
- 城市窗外远景变体；
- 远处庆功宴背景人群循环；

## 10. 禁止生成与后期处理

禁止 AI 直接生成：

- 可读中文、热搜榜、平台 logo、账号名、验证码、数字串、发布时间；
- 真实电影奖名称、奖杯刻字、主持卡片文字；
- 合同、声明、律师函、低姿态回应的可读标题和正文；
- 真实品牌 logo、真实公司名、真实城市地标 skyline；
- 粉丝灯牌海进入颁奖内场；
- 综艺舞台、夜店庆功、婚宴、豪华服务通道、审讯室、公关房科技公司化；
- 张总反派阴笑、怒吼、拍桌、抢手机、保镖押送；
- 沈砚崩溃大哭、抢手机、短剧化对峙。

交给后期：

- 手机/平板/电脑界面；
- 低姿态回应纸面；
- 粉丝监看屏；
- 手机震动/亮灭；
- 摄影闪光；
- 玻璃反射加强；
- 奖杯金属高光；
- 群像脸部虚化和修复；
- 冷暖空间统一调色。

## 11. Showrunner 决策

吸收编剧 reviewer：

- 补庆功宴摄影师/合影执行人员；
- 法务升 P0；
- 明确低姿态回应不是正式道歉；
- 明确前 6 分钟不展示具体黑料；
- 林遥不在前 6 分钟作为具体角色出现；
- 手机离身/屏幕背向他/手机够不到升级为故事资产。

吸收美术 reviewer：

- 增加视觉世界硬规则；
- 锁沈砚、张总外貌与服装细节；
- 奖杯、手机、腕表、胸针、文件夹等进入白底/材质参考；
- P0 空间必须先 moodboard；
- 屏幕/文字/logo 升级为统一后期资产包；
- 助理/运营/公关/法务做视觉区分。
