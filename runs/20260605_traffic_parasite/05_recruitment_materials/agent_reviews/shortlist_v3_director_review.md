# 导演/分镜 reviewer 对素材短表 v3 的意见

1. 主持人、礼仪要保留为一次性功能人物，否则 0:00-0:30 的仪式可信度不成立。

2. 摄影师、媒体记者要保留为功能群演。颁奖摄影区、快门闪光、庆功合影都依赖他们建立现场调度。

3. 场外粉丝不做人设资产，但“外部屏幕/监看屏/隔墙远声”应保留为场景元素。

4. 服务生和酒店后勤不必做主资产，但作为功能群演要出现在服务通道设定里，否则后台空间会假。

5. 助理、运营、公关、法务可以共用职场脸谱，但短表要标清四个功能位：拿手机、发账号、带动线、做权限/回应纸。

6. 香槟杯、门缝冷光、手停半拍、屏幕色块、前景遮挡属于镜头提示词和调度，不应升级为独立资产。

7. 奖杯应强调为“位置关系资产”：手中、入箱、桌边、被冷落，而不是复杂工艺道具。

8. 用户版若保持“人物 / 场景 / 物品”，应把功能人物和功能人群都并入人物，把屏幕与规则并入场景或物品，不要再单列抽象概念。
