# 编剧 reviewer 对素材短表 v1 的意见

1. **“公司资产化”的可视证据还不够。** 沈砚、张总、桌面关系图都服务剧情；但真正让观众理解“被接管”的关键，不只是手机远离他，而是“他的决定权被转移”。建议补“临时公关房间里的签字/确认动作关系图”：沈砚坐着、张总站着或靠近桌边、文件被推到他面前、手机不在手边。文字可不可读，但权力关系要读得懂。

2. **玻璃廊双人倒影构图有叙事价值。** 如果 0:00-6:00 的情绪是从领奖光环滑向后台控制，玻璃倒影很适合表现“表面体面、实际被陪同押送”。它不该只是氛围项，至少要标成关键构图参考。

3. **助理/运营/公关/法务不该做完整群像。** 前 6 分钟真正需要的不是一整套群像，而是功能位：谁拿手机、谁递平板、谁守门、谁准备声明。建议先做功能性 silhouettes / 站位参考，避免资产膨胀。

4. **漏了颁奖礼外部舆论存在感。** 粉丝只在场外屏幕或远声里是对的，但需要轻量参考：场外大屏、粉丝远景、媒体闪光/隔离栏的远距存在感，不需要单独粉丝角色。

5. **奖杯不要过度精修。** 奖杯服务“荣誉变筹码”，重点是位置变化：领奖手中、庆功宴桌边、公关房间角落，而不是奖杯工艺本身。
