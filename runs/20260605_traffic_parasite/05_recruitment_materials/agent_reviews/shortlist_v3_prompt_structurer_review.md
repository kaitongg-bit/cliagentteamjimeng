# 提示词可执行 reviewer 对素材短表 v3 的意见

1. 主持人、礼仪不能被压掉。它们不需要完整人设，但需要作为“颁奖流程人物”保留：主持人持黑信封/获奖卡，礼仪递金色奖杯后退场。

2. 摄影区与媒体记者要保留为功能人群。黑色正装、多台长焦相机、固定摄影区、连拍闪光，这些决定颁奖礼是不是电影奖。

3. 场外粉丝不进人物资产，但“场外屏幕/直播监看/隔墙远声”必须保留。粉丝是画面内容，不是内场人物。

4. 庆功宴社交人群需要单列。品牌方、公司人员、举杯祝贺的人群不需要清晰群像，但需要作为 4-6 人的功能人群保留。

5. 执行人员最好拆成助理、运营、公关、法务四个功能位，不必分别做完整人设，但动作要分清。

6. 服务通道元素不能因为“不单独生成”就彻底消失。清洁车、备餐架、对讲机、消防门、防撞条应保留在场景元素里。

7. 香槟杯、合同、品牌礼盒、花篮、流程卡只进镜头提示词，不做独立资产。

8. 用户版更适合按“核心人物 / 功能人物 / 功能人群 / 核心场景 / 关系物件 / 只进镜头提示词”组织，但如果保持三大类，也要把这些功能位补进人物和场景内部。
