# 美术概念 reviewer 对素材短表 v1 的意见

1. **沈砚视觉锚还不够唯一。** 现在容易生成成泛娱乐男星。建议增加 1-2 个不可替代识别点，比如右眉尾浅断痕、颈侧小痣、略大的礼服外套、眼神总像慢半拍。

2. **张总和沈砚的服装色域太接近。** 两人都是深色西装、白衬衫、低调银色配件，画面里容易混。张总应强化“公司资产管理者”的外貌和服装逻辑，比如更硬的肩线、更规整的领带夹、固定深灰三件套和深蓝领带。

3. **“酒店服务通道到临时公关房间”合并过多。** 服务通道、玻璃隔断、公关房间是三种 mood：冷硬后勤、半透明监控感、临时办公压迫。至少拆成“服务通道”和“临时公关房间”两类，否则生成会混成普通商务酒店走廊。

4. **部分 P1 是镜头构图，不是资产。** “玻璃廊双人倒影构图”“百叶半落的公关房间远景”更像分镜/摄影参考，不一定要进素材资产短表。

5. **职业群像需要最小拆分规则。** “助理/运营/公关/法务职业群像”太泛，建议拆成两类：贴身执行型助理/运营，和冷静文件型公关/法务。
