# 素材资产短表 v3 用户版

## 范围

《流量寄生虫》0:00-6:00：颁奖礼、后台、酒店庆功宴、服务通道、临时公关房间。核心是沈砚从“获奖影帝”被公司温柔接管。

## 人物

### 沈砚

35岁左右，中国男演员。长窄脸，颧骨清楚，眼睛偏窄，眼下有疲惫线；右眉尾有很浅的断痕，颈侧一颗小痣。短黑发向后梳但不油亮，清瘦挺拔，肩线略窄，礼服外套微微偏大。

服装是深午夜蓝近黑礼服、黑缎窄驳领、白衬衫、细黑领结、小银色胸针。

常用状态：职业微笑、眼神慢半拍、摸空口袋、手停在手机边缘又放下。

### 张总

45岁左右，中国男性经纪公司高层。方中带长脸，短发整洁，轻微发际线后移。硬肩线深灰三件套、白衬衫、深蓝窄领带、细领带夹、低调银色腕表。

他不能像反派，应该像专业流程本身。无表情时嘴角也微微上扬。

常用状态：社交微笑、轻压沈砚后背、挡酒、平静推文件、站着俯看桌面。

### 执行人员

不用做完整群像，只分两类即可：

- 贴身执行型助理/运营：拿手机、递平板、扣屏，站位靠近沈砚。
- 文件流程型公关/法务：坐在或站在会议桌旁，处理笔记本、纸面、流程确认。

## 场景

### 正式电影奖内场与舞台侧门

深色木饰面观众席、冷白追光、深色幕布、媒体摄影区、行业观众。粉丝不进入内场，只通过远声、外部屏幕或直播监看存在。

### 高层酒店庆功宴

落地窗、冷蓝城市夜景、暖金室内灯、低矮沙发、细脚茶几、昂贵但空的私人会客区。人群围住沈砚，但不要短剧式大合照。

### 服务通道

冷白荧光灯、灰色防滑地胶、防撞条、消防门、低天花、后勤动线。这里要像真实酒店后台，不像豪华走廊。

### 临时公关房间

玻璃隔断、半透明百叶、小会议桌、笔记本电脑、打印机、冷白屏幕光。外侧仍有庆功宴的暖光，但房间内部已经进入危机处理状态。

## 物品 / 关系资产

### 权限接管桌面

沈砚的手机在桌中央，但不在他手边。张总腕表和文件位置压住手机路径。不可读回应纸被推到沈砚面前，沈砚坐着，张总或公关/法务站着或靠近桌边。

屏幕只出现冷光、色块、输入框轮廓，不出现可读文字。

### 奖杯

虚构金色奖杯，无真实奖项 logo，无清晰刻字。重点不是奖杯工艺，而是它的位置变化：领奖时在沈砚手中，庆功宴时在桌边，公关房间里被冷落在角落。

### 手机 / 平板 / 回应纸

手机和平板都是权限被转移的证据。回应纸不可读，只承担“话已经被别人写好”的视觉功能。

## 不单独准备

香槟杯、清洁车、备餐架、普通文件夹、普通合同、品牌礼盒、花篮、流程卡、对讲机、服务生、普通群演、背景装饰不单独作为素材生成。
