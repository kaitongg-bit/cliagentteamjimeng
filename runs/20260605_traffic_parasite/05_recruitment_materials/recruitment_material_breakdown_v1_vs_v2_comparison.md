# 素材挖掘复盘：v1 vs v2，而不是 single agent 对照

## 复盘结论

这轮《流量寄生虫》0:00-6:00 的素材挖掘实验，原本做了：

- 主素材招募 agent v1；
- 编剧 reviewer；
- 美术概念 reviewer；
- Showrunner 最终整合版；
- single agent baseline。

用户复盘后指出：这个节点不应该追求臭长的素材文档，也不一定需要 single agent baseline。素材挖掘的核心不是“列全”，而是“只筛出真正值得花 token 生图、锁定一致性、后续会反复使用的资产”。

这个判断成立。

## v1 到 v2 的真实变化

| 维度 | v1 主素材 agent | v2 reviewer/Showrunner 后 | 复盘判断 |
|---|---|---|---|
| 完整性 | 已经能覆盖人物、空间、道具 | 更完整，补了法务、摄影师、动作资产 | 增益存在，但不是核心 |
| 文档长度 | 已经偏长 | 更长 | 对 Human 不友好 |
| 生成成本意识 | 有禁文字/logo意识 | 更系统地拆后期资产 | 有价值 |
| 资产筛选 | 仍像生产清单 | 仍保留不少一次性/背景项 | 未达到理想形态 |
| 人物细化 | 不够稳定 | 沈砚、张总细化更好 | 这是应写进素材 agent 的默认规则 |
| reviewer 必要性 | 不确定 | reviewer 主要补规则，但也增加文档重量 | 不应默认启用 |

## 新实验方法

素材挖掘节点以后不再把 single agent baseline 作为主对照。

主对照改成：

1. `v1`：素材招募 agent 独立产出短表。
2. `v2`：只有当 v1 过长、过泛、漏掉叙事关键、人物外貌服装不具体时，才启动 reviewer。
3. 比较 v1 和 v2 是否真的更短、更准、更省生成成本。

如果 v1 已经合格，结论就是：

> 这个节点不需要 reviewer，主素材 agent 足够。

这也是有效实验结果。

## 更新后的素材 agent 标准

素材 agent 不是“完整盘点 agent”，而是“资产筛选 agent”。

只保留：

- 反复出现的人物、空间、道具；
- 需要保持一致的人物外貌、服装、发型、轮廓、配饰；
- 需要单独白底三视图的角色；
- 需要 moodboard 才能判断质感的核心空间；
- 观众必须一眼读懂的叙事道具；
- AIGC 生成容易翻车、必须提前规避的屏幕/文字/手部/多人资产。

不保留：

- 一次性出现的普通物件；
- 普通群演和背景装饰；
- 能直接写进镜头提示词的场景细节；
- 不需要单独生成的香槟杯、清洁车、备餐架、普通文件夹等。

## 对本轮结果的修正评分

| 版本 | 评分 | 说明 |
|---|---:|---|
| v1 主素材 agent | 7.4 | 能干活，但需要更强的“删东西”规则和人物细化规则 |
| v2 reviewer/Showrunner | 7.8 | 补了叙事和视觉规则，但文档更重，Human 可用性下降 |

因此这轮不能证明“素材挖掘节点必须多 agent”。更准确的结论是：

> 应先强化素材招募 agent 的短表规则。reviewer 作为纠偏工具，而不是默认流程。
