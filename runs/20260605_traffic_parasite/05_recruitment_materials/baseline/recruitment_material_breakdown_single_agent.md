| 时间段 | 剧情功能 | 主要画面 | 核心素材需求 |
|---|---|---|---|
| 0:00-1:00 | 沈砚获得影帝，荣耀入口迅速转入后台流程 | 正式电影奖内场、舞台领奖、后台监看屏、侧门关闭 | 颁奖礼舞台、行业观众、主持人、奖杯、摄影区、后台通道 |

| 5:00-6:00 | 公司先写好解释权，沈砚失去第一句话 | 临时公关房间、百叶、打印机、低姿态声明、手机在桌中央 | 小会议室、玻璃隔断、电脑、打印机、文件夹、声明纸、半透明百叶 |

## 7. 禁止生成/后期处理内容

| 禁止项 | 说明 |
|---|---|
| 禁止颁奖内场出现粉丝灯牌海 | 粉丝只能在剧院外、后台监看屏、直播屏或隔墙远声中存在 |
| 禁止综艺舞台、演唱会舞台、偶像MV质感 | 颁奖礼必须是正式电影奖，不是娱乐节目 |
| 禁止可读中文大字、热搜大字蒙太奇、真实平台logo | 所有手机、电脑、平板、声明纸都只能虚化为冷光、色块、灰段落 |
| 禁止真实品牌logo、真实奖项名称、奖杯刻字 | 避免版权和现实指向，也避免画面穿帮 |
| 禁止霸总短剧、反派阴笑、怒吼、拍桌、抢手机、保镖押送 | 恐惧来自流程和礼貌接管，不来自外放冲突 |
| 禁止夸张哭戏、崩溃表演、惊悚门缝、恐怖片构图 | 沈砚在0-6分钟仍维持职业体面，失控是逐步发生 |
| 禁止清晰验证码、账号界面、聊天截图、热搜标题、数字输入 | 权限交接只表现动线和权力，不展示具体可读信息 |
| 禁止多人正脸密集清晰导致脸崩 | 群演可用虚焦、背影、遮挡、局部手部和肩膀 |
| 禁止AI手指畸形和复杂手部动作 | 手机、奖杯、文件夹、香槟杯特写需重点复检 |
| 禁止过度磨皮、广告片高光、奢华摆拍 | 画面要真实、克制、有行业压迫感 |
| 禁止后期添加解释性字幕或功能说明文字 | 不用字幕替代叙事，靠动作、空间、声音和道具表达 |
| 禁止把服务通道拍成豪华酒店走廊 | 必须有冷白荧光、灰色地胶、防撞条、清洁车、备餐架等后场元素 |
