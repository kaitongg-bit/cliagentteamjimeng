# 新规则素材挖掘实验结果：v1 vs v2

## 这次真的重跑了什么

本轮按新规则重跑：

1. 素材招募/资产筛选 agent 输出短表 v1。
2. 编剧 reviewer 只批评 v1，不重写。
3. 美术概念 reviewer 只批评 v1，不重写。
4. Showrunner 吸收有效意见，合成短表 v2。

本轮不做 single agent baseline。素材挖掘节点的验证对象是：reviewer 是否能把同一个主素材 agent 的 v1 变得更短、更准、更省生成成本。

## 结果对比

| 维度 | v1 | v2 |
|---|---|---|
| 文档长度 | 已经明显短于旧长表 | 基本保持短表，没有扩写成长文档 |
| 人物外貌 | 沈砚、张总已有外貌服装 | 增加沈砚唯一识别点；拉开张总和沈砚的服装色域 |
| 空间资产 | 把服务通道和公关房间合并 | 拆成服务通道、公关房间两个 moodboard |
| 叙事资产 | 有桌面权限接管 | 升级为桌面/签字关系资产，更明确“决定权转移” |
| 低价值项控制 | 已排除香槟杯、清洁车等 | 继续排除，并把玻璃倒影/百叶远景移到“构图参考” |
| reviewer 贡献 | 无 | 小幅但明确：不是补更多项，而是纠正资产边界 |

## 结论

这次 v1 已经可用，说明强化后的素材招募 agent 能独立完成大部分工作。

reviewer 的价值不是“补长”，而是：

- 让人物更唯一；
- 拆开容易混的空间；
- 把叙事动作从“道具”升级成“关系资产”；
- 把镜头构图从素材表里剥离，避免生图成本膨胀。

所以素材挖掘节点的推荐流程是：

> 主素材 agent 先出短表 v1；Showrunner 判断是否够用；只有当人物不唯一、空间混、叙事资产不清时，才开 reviewer 做 v2。
