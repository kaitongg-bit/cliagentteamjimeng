# 素材资产短表 v1

## 范围

《流量寄生虫》0:00-6:00：颁奖礼内场、后台冷光侧廊、高层酒店庆功宴、酒店服务通道、临时公关房间。核心是沈砚从“获奖影帝”被温柔接管成“公司资产”。

## P0 必须先锁定资产

1. **沈砚获奖夜人物资产** / 35岁左右中国男演员，长窄脸，颧骨清楚，眼睛偏窄，眼下疲惫线；短黑发向后梳但不油亮，清瘦挺拔，肩线好但非健身感；深午夜蓝近黑礼服西装、黑缎窄驳领、白衬衫、细黑领结、小银色胸针；表情锚点是职业微笑、半秒失神、摸空口袋、手停在手机边缘又放下 / 全片主角，0-6分钟所有权力变化都落在他的脸和身体反应上 / **需要白底三视图**。

2. **张总温和控制者人物资产** / 45岁左右中国男性经纪公司高层，方中带长脸，短发整洁，轻微发际线后移，中等偏瘦；深炭灰西装、白衬衫、深灰或深蓝窄领带、低调银色腕表；表情动作锚点是社交微笑、轻压沈砚后背、挡酒、平静推文件、低声说话 / 不能生成成短剧反派，他的压迫感来自职业化和流程感 / **需要白底三视图**。

3. **正式电影奖内场与舞台侧门** / 深色木饰面观众席、冷白追光、深色幕布、媒体摄影区、行业观众；粉丝只能在场外屏幕或远声里，不进内场 / 开场质感必须像电影奖，不像综艺、演唱会或粉丝应援现场 / **需要 moodboard**。

4. **沈砚奖杯资产组** / 金色虚构奖杯，金属质感，有细小擦痕和指纹，无真实奖项 logo、无清晰刻字；可配黑色泡棉保护箱，但箱子不需独立精修 / 奖杯反复承担“荣耀变资产”的隐喻，近景和反射镜头容易翻车 / **奖杯需要白底参考，不必三视图**。

5. **高层酒店庆功宴主空间** / 落地窗、城市冷蓝夜景、暖金室内灯、低矮沙发、细脚茶几、昂贵但空的私人会客区；人群围住沈砚但不做夸张大合照 / 这里同时承载“被祝贺”和“被排期接管”，多个镜头复用 / **需要 moodboard**。

6. **酒店服务通道到临时公关房间** / 冷白荧光灯、灰色防滑地胶、防撞条、消防门、玻璃隔断、半透明百叶、小会议桌、打印机、笔记本电脑；庆功宴暖光隔在玻璃外 / 这是沈砚从宴会中心被移入危机流程的关键空间 / **需要 moodboard**。

7. **权限接管桌面关系资产** / 沈砚手机在桌中央但不在他手边，旁边有笔记本、平板、不可读回应纸、张总银色腕表压近手机；屏幕只出现冷光、色块、输入框轮廓 / 这是“第一句话被拿走”的动作核心，比单个道具更重要 / **需要一张桌面关系参考图，不需要三视图**。
