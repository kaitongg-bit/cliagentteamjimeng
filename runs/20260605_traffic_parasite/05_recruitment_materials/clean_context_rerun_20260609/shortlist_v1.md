# 《流量寄生虫》0:00-6:00 素材资产短表 v1

## 1. 范围

覆盖 0:00-6:00：电影奖内场领奖 -> 剧院后台侧廊 -> 高层酒店庆功宴 -> 酒店服务通道 -> 临时公关房。
这一段的核心不是“爆雷现场”，而是沈砚从公众荣耀进入公司接管，手机、账号和第一句话一起离手。

## 2. 人物

- **沈砚**：35岁左右中国男演员，偏高偏瘦，肩线利落，脸部轮廓清晰，眼下有轻疲态；黑发短而整齐，正式侧分或后梳；深午夜蓝礼服西装、黑色缎面枪驳领、白衬衫、黑领结、黑皮鞋，可带低调银色胸针。动作锚点：第一排起身扣西装纽扣、接奖杯、职业微笑、摸空口袋、伸手想拿手机又停住、坐在冷白会议室里轻声说“我没有”。
- **张总**：45岁左右中国男性经纪公司高层，中等偏壮，站姿稳，压迫感来自距离和节奏，不来自夸张表情；短发整洁，鬓角可有轻微灰；深炭灰西装、深色领带、银色腕表。动作锚点：挡酒、扶后背、并肩贴近半步在前、接管路线、对执行组下口令、把文件夹推到沈砚面前。
- **公司执行组（助理 / 运营 / 公关法务）**：25-35岁都市职业人群，黑白灰商务装，轮廓利落不过度时装化；助理可拿奖杯保护箱和手机，运营常拿平板或手机背屏操作，法务带笔记本电脑与文件夹。动作锚点：接走奖杯、扣住手机屏幕、递手机又收回、拉百叶、插打印机、推“低姿态版本”文件夹。
- **颁奖礼功能人群（主持人 / 礼仪 / 摄影记者）**：主持人正式晚礼服或黑色礼服西装，礼仪低调黑色礼服，摄影记者黑色正装配专业相机；整体专业、克制，不综艺化。动作锚点：主持人宣奖、礼仪递奖杯后退场、摄影区连拍反打、行业嘉宾鼓掌让路。
- **酒店服务功能人群（服务生 / 备餐与清洁人员）**：中性低存在感制服，黑白服务装或浅灰工作服，不抢戏；用于建立服务通道和庆功宴后场的真实度。动作锚点：贴墙让路、推清洁车、经过不锈钢备餐架、门开合时一闪而过。

## 3. 场景

- **正式电影奖内场舞台**：深色木饰面观众席 + 中央冷白追光舞台 + 深色幕布 + 摄影区；空间关系是“台上被看见，台下是行业目光”，质感庄重、真实、非综艺。
- **剧院后台侧廊**：低天花、灰色地胶、防撞条、黑色航空箱、电缆、花篮、设备箱把通道压窄；冷白荧光灯，声音应是对讲机、脚步、箱扣声，形成从荣耀到流程的落差。
- **高层酒店庆功宴私人区**：落地窗外冷蓝城市夜景，室内暖金灯，低矮沙发、细脚茶几、香槟杯、品牌礼盒、合同文件；昂贵但空，热闹感像围猎，不像婚宴或夜店。
- **酒店服务通道 / 备餐侧廊**：灰色防滑地胶、不锈钢备餐架、清洁车、消防门、冷白荧光灯；门一关，宴会声被压成低频，这里是“公众空间”切到“公司内部流程”的关键过道。
- **临时公关房 / 玻璃小会议室**：靠近庆功宴的玻璃会议室，半透明百叶、冷白会议光、笔记本电脑、打印机、文件夹、充电线；玻璃外仍看见暖金庆功宴，形成“庆功继续，他失去解释权”的双空间对照。

## 4. 物品 / 关系资产

- **金色奖杯 + 黑色泡棉保护箱**：前半段是荣誉，进入后台后立刻变成“资产入箱”；用于连接领奖、后台、庆功宴三段。
- **沈砚的手机（含账号控制权）**：手机始终在别人手里，屏幕只要冷光和模糊界面，不做可读内容；它代表“他的第一句话已经不归他自己”。
- **临时公关处置套件**：文件夹、打印纸、笔记本电脑、平板、桌面充电线、半拉百叶；不是要做复杂 UI，而是要把“统一口径、先发低姿态版本”的处理气味立住。
- **张总与沈砚的控制关系**：这段要锁定成“温和接管”而非暴力冲突，具体体现为挡酒、扶背、并行站位、隔开人群、推文件夹、让手机始终够不到。

## 5. 不单独准备

行业观众、品牌方、普通香槟杯与礼盒、花篮、电缆、清洁车、备餐架、普通工作人员、不可读的屏幕文字与声明正文，都直接写进镜头提示词或交后期处理，不单独做素材资产。
