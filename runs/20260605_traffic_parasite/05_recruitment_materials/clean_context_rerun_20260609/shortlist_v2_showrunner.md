# 《流量寄生虫》0:00-6:00 素材资产短表 v2

## 1. 范围

覆盖 0:00-6:00：电影奖内场领奖 -> 剧院后台侧廊 -> 高层酒店庆功宴 -> 酒店服务通道 -> 临时公关房。
这一段的核心不是“爆雷现场”，而是沈砚从公众荣耀进入公司接管，手机、账号和第一句话一起离手。

## 2. 全段规则

- 正式电影奖，不是综艺、演唱会或短剧舞台。
- 内场没有粉丝灯牌，没有平台 logo，没有可读中文，没有可读声明正文。
- 手机、平板、电脑、打印纸、输入框、验证码都保持不可读，只保留冷光、模糊界面、灰段落和输入轮廓。

## 3. 人物

- **沈砚**：35岁左右中国男演员，偏高偏瘦，肩线利落，脸部轮廓清晰，眼下有轻疲态；黑发短而整齐，正式侧分或后梳；深午夜蓝礼服西装、黑色缎面枪驳领、白衬衫、黑领结、黑皮鞋，可带低调银色胸针。资产表只保留可复用姿态：被摆回镜头中心、摸到空口袋、伸手够手机但够不到、隔桌坐下被迫听安排。

- **张总**：45岁左右中国男性经纪公司高层，中等偏壮，站姿稳，短发整洁，鬓角可有轻微灰；深炭灰西装、深色领带、银色腕表。控制规则不是情绪词，而是行为链：永远半步在前、替沈砚答话、把人从公开空间导入内部空间、用文件和站位取代争吵。

- **公司执行组**：保留四个功能位，不做四套完整人设。
  助理：持奖杯、持手机、带动线。
  运营：背屏操作、处理账号、递平板。
  公关：围桌控口径、推回应纸、调度百叶和空间。
  法务：接电脑或第二部设备、做权限/文件交接。

- **颁奖礼功能人群**：主持人、礼仪、摄影记者、行业嘉宾都保留。主持人持黑信封或获奖卡，礼仪递奖杯后退场，摄影记者在固定摄影区连拍，行业嘉宾鼓掌让路。

- **庆功宴功能人群**：品牌方、公司人员、合影摄影师单列为功能人群，负责围站、敬酒、合影、把沈砚重新摆回资产展示位。

- **酒店后勤人群**：服务生、备餐和清洁人员作为低存在感功能人群保留，用于让服务通道和后场真实成立。

## 4. 场景

- **正式电影奖内场舞台**：深色木饰面观众席、中央冷白追光舞台、深色幕布、固定摄影区；空间关系是“台上被看见，台下是行业目光”。

- **舞台侧门与后台监看屏**：舞台侧门、后台监看屏、灰色地胶、防撞条、电缆、航空箱一起构成第一段转场锚点，用来把公众荣耀切到内部流程。

- **剧院后台侧廊 / 玻璃廊 / 电梯口**：低天花、设备箱压窄通道、冷白荧光灯、门禁和玻璃反射；这里承担 0:45-1:45 的动线过渡。

- **高层酒店庆功宴私人区**：落地窗外冷蓝城市夜景，室内暖金灯，低矮沙发、细脚茶几；热闹感像围猎，不像婚宴或夜店。

- **庆功宴合影位**：落地窗前固定站位点、闪光灯方向、合影摄影师、品牌方围站位置。这不是普通寒暄，而是把他身体摆回资产展示位的场面。

- **酒店服务门与服务通道**：服务门、灰色防滑地胶、不锈钢备餐架、清洁车、消防门、冷白荧光灯；这里是“公众空间”切到“公司内部流程”的第二个视觉开关。

- **临时公关房 / 玻璃会议室**：半透明百叶、冷白会议光、笔记本电脑、打印机、文件夹、充电线；玻璃外仍有暖金庆功宴。还要锁定门口、半拉百叶、桌位和站位关系。

## 5. 物品 / 关系资产

- **奖杯流转链**：领奖时在沈砚手里 -> 后台入黑色泡棉保护箱 -> 庆功宴桌边陈列 -> 合影时短暂塞回他手里 -> 再被拿走。重点不是工艺，而是位置变化。

- **手机与设备控制链**：手机不只是“在别人手里”，而是有顺序：助理持机，运营背屏操作，公关围桌控口径，法务完成权限或设备交接。必要时可出现第二部设备或电脑，但所有屏幕保持不可读。

- **临时公关处置套件**：文件夹、打印纸、笔记本电脑、平板、桌面充电线、半拉百叶。声明正文不是资产，但“不可读纸面 / 不可读屏幕”是生成阶段必须锁死的规则。

- **临时公关房站位关系**：沈砚先站门边，没有座位；后来隔桌坐下；手机放桌中央够不到；张总或公关站着或靠近桌边把文件推过来。这是 5:00-6:00 压迫感的核心关系资产。

- **张总控制规则**：挡酒、扶背、并肩贴近、替答、导流、推文件，不直接和沈砚发生外放冲突。

## 6. 不单独准备

普通香槟杯、普通礼盒、花篮、电缆、门轴声、对讲机声、打印机声、一次性台词、单次小动作、普通工作人员、不可读声明正文都不单独做素材资产；它们回到镜头提示词或后期层处理。
