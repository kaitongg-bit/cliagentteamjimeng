# 提示词可执行 reviewer

- 需要补：把“非综艺 / 非短剧 / 内场无粉丝灯牌 / 无可读中文 / 无平台 logo”提成全段顶层约束，不要只散在描述里。
- 需要补：把“屏幕/纸面不可读规则”升级成全设备规则，覆盖手机、平板、电脑、打印纸、输入框、验证码。
- 需要补：庆功宴里的“品牌方 / 合影摄影师”应独立成功能人群，不要继续并入普通工作人员。
- 需要补：把“后台监看屏 / 服务门”列成转场锚点。它们不是一次性装饰，而是“公众荣耀切到公司流程”的视觉开关。
- 需要改：“不可读的屏幕文字与声明正文，都直接写进镜头提示词或交后期处理”这句要拆开。声明正文可不做资产，但“不可读屏幕/文档”不能降给后期，必须在生成阶段先卡死。
- 需要改：公司执行组现在按岗位名罗列还不够，建议补成动作分工链：助理持机，运营背屏操作，公关控口径，法务完成权限/文件交接。
- 应降级到镜头提示词：人物动作锚点里过于一次性的单镜头动作/台词，比如“第一排起身扣西装纽扣”“坐在冷白会议室里说‘我没有’”；资产表保留可复用关系姿态就够了。
