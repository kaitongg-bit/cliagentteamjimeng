# 《流量寄生虫》前3分钟现实性修正 v3

## 修正点：颁奖现场是否真的有粉丝应援？

如果按“电影级正式行业奖项”处理，内场不应该拍成粉丝灯牌海。  
内场更可信的是：

- 电影人、评委、公司高层、品牌方、媒体摄影区；
- 礼貌但强烈的掌声；
- 摄影记者连拍；
- 主持人扩声；
- 偶尔从剧院外、红毯区、后台监看屏传来的粉丝声。

粉丝应援应放在：

1. 剧院外红毯围栏外；
2. 后台监看屏里的直播画面；
3. 工作人员平板上的社媒热度页面；
4. 门后被隔住的远处喊声。

这样更电影，也更符合“沈砚是被公共爱意和商业流程同时包装的人”。

## 修正点：即梦镜头调度单位

前一版 10-16 秒一个 shot_id 写得太像粗分镜，不适合直接发给即梦。  
但把每个 3-5 秒 micro-shot 都单独发给即梦也不对，因为即梦单次视频生成通常可以到 10-15 秒，真正可执行的单位应该是：

- 一条即梦提示词 = 一个 10-15 秒视频；
- 提示词内部用 0-3s / 3-6s / 6-10s / 10-15s 描述镜头调度；
- 每个时间段只承担一个动作或信息功能；
- 声音、台词、现场氛围可以写在同一条提示词里，作为生成和后期参考；
- 复杂场面用 12 条左右的 15 秒视频剪成前 3 分钟。

micro-shot 的作用不是最终投喂模型，而是帮提示词 agent 先拆清楚画面逻辑：

- 一个 micro-shot 只做一个动作；
- 只承担一个空间/关系/信息功能；
- 不依赖模型一次完成过多人物调度；
- 最后再合并成可发即梦的 10-15 秒视频提示词。

示例：

原：TP_010 “张总替沈砚挡酒，手停在后背”，10 秒。  
拆：

1. 2:08-2:13 品牌方递酒，张总手伸入画面；
2. 2:13-2:18 张总挡酒并说“今天你不用挡”；
3. 2:18-2:23 张总手停在沈砚背上，腕表反冷光。

这样才像可执行的视频生产，而不是一张电影概念图。

## 修正点：提示词不应太短或太概括

短提示词不是“随便短”。它应该短在不重复公共层，具体在动作、景别和空间关系。

每条提示词必须包含：

- 景别/镜头；
- 主体是谁；
- 只做一个动作；
- 场景真实材质；
- 光线方向；
- 负面约束。

不应该只写：

> 沈砚站在舞台领奖，电影感。

应该写：

> 50mm中近景，沈砚穿深午夜蓝礼服西装走到麦克风前，手握金色奖杯，吸气后露出职业微笑，背景行业观众席虚化，冷白追光，真实皮肤纹理，克制电影表演。
