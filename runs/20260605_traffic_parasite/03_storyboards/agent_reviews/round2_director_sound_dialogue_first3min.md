# 《流量寄生虫》前3分钟声音/台词设计

导演 agent round2：声音与台词层  
范围：前 3 分钟，TP_001-TP_014  
核心判断：掌声是真的，但它必须在三分钟内被剪辑成系统噪音，让观众听见沈砚从“人”变成“可管理资产”的过程。

## 1. 颁奖环节声音策略

颁奖环节需要主持人，但主持人不能成为叙事人物。主持人声音只作为行业仪式的“认证声”出现，内容极短、清楚、官方，最好在 TP_001 前半段或 TP_002 进入麦克风前完成：

> “最佳男主角，沈砚。”

这句可以清晰听见，但不要热血，不要综艺腔。它的功能不是制造荣耀，而是给沈砚盖章。

获奖词需要，但不需要完整。沈砚只保留 2-3 个清晰碎片，其他被掌声、闪光、粉丝喊声和后续后台噪音吞掉。建议清楚听见：

- “谢谢评委。”
- “谢谢所有还愿意相信电影的人。”
- “我会继续好好演戏。”

其中“相信”是本段最重要的词，后续塌房和粉丝分裂都会反咬它。

粉丝和记者背景音都需要，但分层处理。粉丝声音是人声，有热度、有信任；记者声音是机械触发，快门、连拍、喊名字、要视线。粉丝不要喊成偶像应援现场，记者不要像红毯吵闹。整体应像正式电影奖现场里短暂失控的关注。

可用背景碎片：

- 粉丝远处：“沈砚，看这里。”“我们一直在。”
- 记者近处：“沈砚老师，正面。”“奖杯抬一下。”
- 主持/礼仪远处：“请留步合影。”

## 2. 清晰台词与环境碎片

必须清晰听见的台词只有四类：

1. 主持人宣布：“最佳男主角，沈砚。”
2. 沈砚获奖词碎片：“谢谢所有还愿意相信电影的人。”
3. 张总前置温柔控制：“慢点，今天你不用挡。”
4. 张总主题句：“你现在不是人，是资产。”

可以作为环境音/碎片的内容：

- 粉丝喊名、记者喊视线、礼仪催流程。
- 工作人员后台口令：“侧门开一下。”“奖杯先收。”“下一场候场。”
- 助理/商务碎片：“明天十点品牌采访。”“热搜词已经定了。”“账号文案我发你。”
- 庆功宴客套：“恭喜恭喜。”“今年太稳了。”“品牌那边很满意。”

这些碎片不追求完整语义，功能是让观众感到沈砚身边一直有人说话，但没有一句真正问他感受。

## 3. 从掌声到系统噪音的声音递进

声音曲线要从“人的崇拜”变成“系统运转”：

- TP_001-TP_004：掌声、欢呼、快门、人名呼喊都是真实的，空间大，混响长。观众应该相信他真的被爱着。
- TP_005：侧门关闭是第一次声音剪刀。掌声被门板闷住，高频被削掉，后台荧光灯嗡鸣第一次露出。
- TP_006-TP_007：掌声退成低频残响，取代它的是脚步、对讲机、电缆拖地、航空箱轮子、编号贴撕开的声音。奖杯进入保护箱时，金属轻响要像物品入库。
- TP_008-TP_011：酒店宴会把掌声伪装成社交噪音。香槟、玻璃、轻笑、商务寒暄叠在一起，但节奏越来越像排期、报价、曝光量、合同流程。
- TP_012-TP_014：张总主题句后，宴会声短暂抽空，随后只剩空调、城市低频、平板提示音、服务通道门轴和远处对讲机。掌声已经不在了，但它的节奏被设备声继承。

声音不做恐怖片处理，不用明显心跳或尖锐音效。压迫感来自正常声音被过度清楚地听见。

## 4. 张总主题句落地方式

“你现在不是人，是资产”不能演成威胁，也不能演成短剧反派金句。张总说这句话时，他本人应该真心认为这是高级保护、行业经验和亲近提醒。

表演方向：

- 音量低，但不是暧昧耳语；像在嘈杂宴会里替沈砚省掉外界误解。
- 语速慢半拍，中间不停顿太久，避免“金句化”。
- 表情温和，嘴角有社交笑，眼睛看向前方或看酒杯，不死盯沈砚。
- “不是人”不要加重，“资产”也不要咬狠；整句像一句财务常识。
- 说完后立刻接一个自然动作：替他拿走酒杯、拍背、示意助理记录明天行程。不要让台词悬在空中等观众鼓掌。

建议完整落地台词：

张总先挡酒，轻声：“慢点，今天你不用挡。”  
半拍后，仍然带笑：“你现在不是人，是资产。”  
再接一句更日常的补刀：“资产要养，不能随便耗。”

最后一句可根据节奏选择保留或压成半环境音。如果保留，它能让张总不反派，因为他不是在羞辱沈砚，而是在用行业逻辑照顾他、占有他。

## 5. Shot-by-shot 声音/台词建议

| shot_id | 声音/台词建议 |
|---|---|
| TP_001 | 大厅掌声和低频混响铺满，主持人清楚宣布“最佳男主角，沈砚”，随后粉丝喊名从观众席深处浮上来。 |
| TP_002 | 沈砚走向麦克风时先听见呼吸和奖杯握柄轻响，获奖词只清楚留“谢谢所有还愿意相信电影的人”。 |
| TP_003 | 快门连拍和闪光灯充电声变得比掌声更近，奖杯金属轻碰麦克风架，荣耀开始带锋利感。 |
| TP_004 | 粉丝喊声作为温暖碎片：“我们一直在”“沈砚看这里”，但灯牌电流声和手机提示音轻轻压在人声下。 |
| TP_005 | 侧门关闭瞬间削掉掌声高频，后台荧光灯嗡鸣、门锁回弹、远处对讲机口令接管声场。 |
| TP_006 | 跟拍中保留工作人员碎片：“这边走”“下一段采访取消吗”，沈砚笑容未收，但他的声音不用回应。 |
| TP_007 | 奖杯入箱的海绵摩擦、金属轻响、编号贴撕开声要清楚；助理低声说“奖杯先收”，像资产登记。 |
| TP_008 | 玻璃廊里城市低频和皮鞋声变空，张总温和闲话只露半句：“今晚别自己扛，后面都排好了。” |
| TP_009 | 宴会声热闹但失焦，清楚听见杯壁相碰和“恭喜”，商务碎片“品牌那边很满意”从人群里划过。 |
| TP_010 | 张总挡酒时清楚说“慢点，今天你不用挡”，手压后背的布料摩擦声比酒桌笑声更近。 |
| TP_011 | 平板提示音、指尖滑屏、排期碎片成为主声：“明天十点采访”“热搜词已经定了”，沈砚在远处被静音成画面。 |
| TP_012 | 宴会声微微抽空，张总平静说“你现在不是人，是资产”，不要低音炮处理，只让空调声在句尾露出来。 |
| TP_013 | 沈砚先笑，笑声短而礼貌，随后半拍空白；手指碰胸针或摸空口袋的细声成为他的真实反应。 |
| TP_014 | 远处服务通道门开合、对讲机和清洁车轮声接替宴会掌声，张总上一句“资产要养，不能随便耗”可作为远处残音消失。 |

## 6. 给剪辑与声音的总执行提醒

不要把前三分钟做成“暴风雨前的宁静”。这里不是预告片钩子，而是一次正常行业流程里，人被自然归档的过程。所有声音都应该合理、日常、克制；越合理，越可怕。
