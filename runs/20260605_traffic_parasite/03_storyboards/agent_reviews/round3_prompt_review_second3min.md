# 《流量寄生虫》3:00-6:00 提示词审查摘要

## 评分

v1 结构合格，评分 7/10。建议先小样，不建议直接全量生成。

## 主要问题

1. `02` 手机刷脸、复制、切换账号动作过细，容易生成手和界面错误。
2. `08` 验证码风险最高，容易出现可读数字，也不适合让“读数字”成为画面核心。
3. `09` 临时公关房间元素太多，屏幕类型太复杂。
4. `12` 冷暖空间、百叶、手机亮灭、推声明、关门、对白同时出现，15 秒内容易混乱。
5. 部分台词偏直给，如“保护你”“先低头，等风过去”“现在不是讲事实”。

## 已吸收修改方向

1. 手机界面只保留冷光、色块、输入框轮廓，不出现可读内容。
2. 弱化刷脸、验证码、复制账号等复杂动作，改成“屏幕背向沈砚、工作人员熟练操作”。
3. 台词改成更职业、更轻、更冷的公关话术。
4. `09` 只保留一台模糊电脑、打印机、文件夹。
5. `12` 只保留冷暖空间对照和手机亮灭，不再加服务通道门关闭。
6. 将“外面还不知道”改成“还没扩散到主场”，避免现实逻辑矛盾。
