# Prompt Structurer Review - first 3min round1

审查对象：`first3min_storyboard_prompts_v1.md`  
参考依据：`prompt_structurer.yaml`、前3分钟人物与场景设定、132分钟剧情梗概开场段

## 1. 总体判断

现版已经具备“短结构提示词卡”的基本形态：每个镜头都有画面目标、主体动作、空间道具、镜头构图、光线质感、负面约束、短提示词和备注，符合可追溯到 shot_id 的要求。

主要问题是：每张卡的“即梦短提示词”仍偏句子化，常把主体、动作、空间、镜头、光线、质感压成一整段；从人审角度可读，但从批量生产角度不够稳定。建议下一版把固定连续性抽到公共层，每个镜头只写变量。

## 2. 是否仍冗长

结论：中度冗长，不是长 prompt，但还不是最优短卡。

- 多数单条短提示词在可控范围内，但信息密度偏高。
- “电影感、真实、克制、质感”等形容词重复出现，可抽到全局 style_rules。
- 沈砚年龄、服装、张总年龄、服装不必每镜重复，可进入人物连续性。
- 场景材质与灯光规则已经在 bible 里明确，单镜只保留变化点即可。
- 备注多数是导演意图，不宜进入即梦执行提示词，可保留在人审栏，但不进入生成栏。

## 3. 自相矛盾与执行风险

### TP_001

- “远景”与“32岁中国男演员”并不冲突，但远景无法稳定看出年龄与面部细节。年龄应放人物连续性，不放该镜头变量。
- “虚假灯牌文字”与“蓝白粉丝灯牌海”可兼容，但若要求可读文字会增加错字风险；本镜应只要灯牌海，不要具体字。

### TP_003

- “奖杯反光里映出沈砚半张脸和相机闪光”执行难度较高，但不矛盾。应减少人物精细表情要求，强调金属反射和半脸切割即可。
- “不要奖杯文字错误”说明奖杯文字风险存在，最好避免生成可读奖杯刻字。

### TP_006 / TP_013

- 屏幕信息承担“品牌祝贺、代言确认、热搜排期、通稿标题”等叙事功能，但又要求“不要错误大段中文”。建议固定为“不可读界面、虚化中文块、排期表格感”，不要让模型生成具体文字。

### TP_008

- “电梯/玻璃反射”与“高层酒店玻璃走廊”不矛盾，但场景核心应二选一突出：玻璃廊反射优先，电梯门作为可选背景。
- “两人影子重叠”与“并肩走”可执行，但不应再要求复杂对话表演；动作保持“张总靠近说话”即可。

### TP_009

- “28mm广角”与“沈砚被人围住”适配，但如果人数过多会增加多人脸崩坏。建议限制为 4-6 名宾客虚焦围绕。

### TP_010

- “手轻压后背”与“挡下一杯酒”同镜可执行，但动作中心有两个。短卡应优先“手压后背”，挡酒作为环境动作弱化。

### TP_011

- “耳边低声说话”容易被模型误读为暧昧，需要负面约束固定“非亲密、非暧昧、非威胁”。现版已有，但建议进入共通负面或该镜强负面。
- 台词不进入提示词是正确的。即梦画面提示词无法稳定表达台词语义，应靠贴近距离、半侧光、沈砚微僵反应承载。

### TP_014

- “走廊尽头”与“从宴会暖光区域望向服务通道”空间成立。
- “后场标识”可能带来错误中文，建议改为“模糊后场标识”或删除。
- “不要悬疑夸张音效感”不是画面约束，可改为“不要恐怖片光影、不要夸张惊悚构图”。

## 4. 应固定为连续性/负面约束的字段

### 人物连续性

- 沈砚：32-36岁中国男演员，清瘦高挑，骨相干净，深色定制西装，白衬衫，低调胸针，红毯妆发，专业微笑下有轻微疲惫。
- 张总：45-55岁中国经纪公司老板，深灰商务西装，低调腕表，温和社交笑，靠近时有控制感，非脸谱反派。
- 表演基调：沈砚不惨不崩溃，张总不阴笑不威胁；压迫来自距离、手势、空间和反射。

### 场景连续性

- S1颁奖礼：宽阔舞台、深色观众席、蓝白灯牌海、冷白追光、金色奖杯。
- S2后台侧廊：白色冷光墙面、设备箱、黑衣工作人员、手机和平板、忙乱但真实。
- S3高层酒店庆功宴：落地玻璃、城市夜景、香槟、品牌礼盒、合同文件、暖金室内灯与冷蓝窗光冲突。
- 光线递进：舞台冷白追光 -> 后台硬冷白 -> 宴会暖金/冷蓝混合 -> 服务通道冷白。
- 物件连续：奖杯从舞台到后台再到宴会桌边；手机/平板只提示运作，不出现塌房新闻正文。

### 风格连续性

- 真实真人电影长片质感，浅景深，空间纵深，奢华表面下偏冷。
- 非广告大片、非综艺红毯、非短剧、非AI概念图。
- 色彩控制为冷白、黑西装、深灰、香槟金、屏幕冷蓝，避免梦幻紫和过饱和娱乐海报感。

### 共通负面约束

- 短剧质感、综艺舞台、广告硬摆拍、过度磨皮、AI塑料皮肤、偶像写真、霸总短剧。
- 夸张反派表情、黑帮威胁感、耳语暧昧感、夸张哭戏。
- 错误中文标识、清晰大段屏幕文字、文字水印、奖杯刻字错误。
- 畸形手指、多人脸崩坏、过度金色、夜店感、婚宴感、恐怖片门缝。

## 6. 下一版建议

建议把文件拆成三层：

1. 共通层：人物连续性、场景连续性、风格连续性、共通负面约束。
2. 镜头层：每个 shot 只写画面目标、变量动作、镜头构图、光线变化。
3. 生成层：即梦短提示词控制在 90-150 中文字，不重复全局设定。

这样能减少每镜冗余，也能降低人物漂移、场景漂移和屏幕错字风险。
