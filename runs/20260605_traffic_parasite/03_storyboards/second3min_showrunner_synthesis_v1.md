# 《流量寄生虫》3:00-6:00 showrunner 收敛 v1

## 本轮 agent team 结论

本段不是“热搜爆了”，而是“沈砚的解释权在热搜真正落下前，已经被公司流程接管”。

3:00 承接前 3 分钟：沈砚还在庆功宴人群里，手机不在自己手里，远处服务通道冷白光开合。  
6:00 收束到：临时公关房间里，声明、账号、手机、法务电脑都在桌上，沈砚本人却不是发言中心。

## 吸收各 agent 的意见

编剧 agent：

- 保留“手机在别人手里 -> 解锁 -> 账号替他说话 -> 声明替他说话”的层层剥离。
- 不让张总太早显得像阴谋主谋，而是像专业保护者。
- 不展示完整黑料，只展示工作人员反应和危机流程。

导演 agent：

- 空间动线采用：庆功宴主厅 -> 服务门 -> 冷白服务通道 -> 侧廊 -> 临时公关房间。
- 使用门框、玻璃、百叶、桌面前景遮挡，把沈砚从中心挤到边缘。
- 屏幕只做光源和证据形状，不做信息板。

剪辑/声音 agent：

- 庆功宴声贯穿，不要进入大灾难音乐。
- 热搜信息不用文字解释，而用“谁拿着手机、谁围成小圈、谁被打断”叙事。
- 关键声音：手机震动、门轴、平板触控、电话免提、打印机、隔墙庆功声。

## 本段核心动作

1. 沈砚仍被祝贺，但手机在助理手里。
2. 手机震动，工作人员比沈砚先知道异样。
3. 张总以“保护”为名把他带离宴会主厅。
4. 服务通道里，账号权限开始被集中。
5. 临时公关房间里，证据碎片出现，但不可读。
6. 公司先写好了“统一口径”。
7. 沈砚第一次轻声拒绝，但没有爆发。
8. 外面庆功继续，里面他已经失去第一句话。

## 不做什么

- 不做满屏热搜弹窗。
- 不展示清晰聊天记录、监控图、声明正文。
- 不让沈砚怒吼、哭、拍桌。
- 不让张总阴笑、威胁、霸总化。
- 不在 3:00-6:00 展开品牌解约、粉丝分裂、全网辱骂。
