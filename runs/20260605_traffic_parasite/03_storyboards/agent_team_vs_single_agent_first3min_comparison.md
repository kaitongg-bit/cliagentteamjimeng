# 《流量寄生虫》前3分钟提示词：agent team vs single agent 对比

## 对比对象

agent team 版：`first3min_jimeng_video_prompts_v4.md`  
single agent 版：`single_agent_baseline_first3min_jimeng_prompts.md`

本次对比只证明这个 case 的结果，不等于统计意义上的普遍结论。它适合给老板看作“过程产物差异”的一个样本。

## 实验隔离

single agent baseline 只拿到：

- 原始文档：`02_agent_team/drafts/traffic_parasite_revised_outline_v1.md`
- 任务：为前 3 分钟写 12 条即梦视频提示词，每条 10-15 秒

single agent 没有拿到：

- 美术/人物/场景 bible；
- 导演 agent 意见；
- 声音/台词层；
- micro-shot 拆解；
- 用户关于即梦 10-15 秒生成单位的纠偏；
- “正式电影奖内场不应是粉丝灯牌海”的现实性修正。

## 关键差异

| 维度 | agent team v4 | single agent baseline | 观察 |
|---|---|---|---|
| 即梦工具适配 | 一条提示词对应 10-15 秒，内部有 0-3s / 3-6s / 6-10s / 10-15s 调度 | 一条也是 15 秒，但很多条内部调度较粗 | single agent 能跟格式，但细分动作密度不稳定 |
| 现实性 | 正式电影奖内场是行业观众、评委、摄影区；粉丝只在场外/监看屏/远声 | 直接写“粉丝灯牌连成一片”在颁奖礼内场 | agent team + human 纠偏修正了原始文档里的不真实设定 |
| 连续性 | 先宣布、起身、上台、领奖、奖杯入箱，动作顺序清楚 | 第 1 条还没上台就“手握影帝奖杯”，第 2 条又站在领奖台 | single agent 有明显道具连续性 bug |
| 叙事节奏 | 前 3 分钟集中拍“荣耀被流程接管”，爆料危机尚未落下 | 1:30 就开始同步爆料，3:00 已进入账号接管危机 | single agent 更像剧情梗概压缩，少了电影短片开场的呼吸 |
| 人物关系 | 张总通过挡酒、拿杯、手停后背、排期平板体现控制 | 张总主要通过台词和危机会议体现控制 | agent team 版更依赖可见动作，不靠解释 |
| 影调连续 | 冷白舞台、后台荧光、酒店暖金、服务通道冷光形成梯度 | 有“金色灯海”“冷金宴会”“屏幕冷光”，但空间层次不够稳定 | agent team 版更像经过美术/导演统一 |
| 生成风险控制 | 明确限制多人脸、可读中文、品牌 logo、内场粉丝、奖杯刻字 | 也有负面约束，但部分风险来自正向提示词本身 | agent team 版更懂模型会在哪些地方翻车 |

## 可以给老板看的结论

这次 case 里，single agent 并不是完全不能产出，它能快速给出一套结构完整的 12 条提示词。但它更容易：

1. 直接继承原始文档中的不真实设定；
2. 出现道具和动作连续性错误；
3. 把剧情推进得太快，像压缩梗概；
4. 更依赖台词和氛围词，缺少具体可见动作；
5. 对 AIGC 视频生成的失败点控制不够细。

agent team 版的优势不是“文采更好”，而是过程里多了几层质量阀：

1. 美术/导演层统一了空间、影调、真实感；
2. 分镜层把剧情拆成可拍动作；
3. 声音/剪辑层补了现场氛围和转场；
4. 提示词层把它压成即梦 10-15 秒生成单位；
5. Human 纠偏及时指出工具使用单位和现实性问题；
6. Showrunner 最终收敛，避免各 agent 互相堆料。

## 盲评建议

下一步不要只读文本判断。建议各选 4 条去即梦生成：

agent team v4：

- `01 0:00-0:15`
- `04 0:45-1:00`
- `09 2:00-2:15`
- `12 2:45-3:00`

single agent baseline：

- `1｜00:00-00:15`
- `2｜00:15-00:30`
- `4｜00:45-01:00`
- `11｜02:30-02:45`

盲评时隐藏文件名，只看生成视频，按 1-5 分评：

- 是否像电影而不是短剧/综艺；
- 空间和行业现实是否可信；
- 人物动作是否连续；
- 是否有可剪辑的 15 秒内部节奏；
- 是否减少 AIGC 常见错误；
- 是否服务《流量寄生虫》的主题。
