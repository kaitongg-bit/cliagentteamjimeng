# 《流量寄生虫》前3分钟分镜/提示词 Round 1 Showrunner 综合

## 本轮参与 Agent

- 导演 Agent：检查电影级、戏剧功能、表演动作、空间压迫。
- 美术概念 Agent：检查人物连续性、空间差异、材质/色彩/摄影规则。
- 细分镜 Agent：检查 shot list、时长、轴线、道具连续、图生视频可执行性。
- Prompt Structurer Agent：检查提示词冗余、自相矛盾、连续性层与短提示词结构。

## 核心结论

v0 方向成立：前3分钟不是拍塌房，而是拍“高光正在变成陷阱”。  
但 v0 仍偏“高光展示 + 屏幕说明”，需要收紧为“温柔资产交接现场”。

下一版必须做四件事：

1. **减少屏幕说明。** 屏幕只能作为系统感，不承担主要剧情信息。
2. **增加身体动作。** 奖杯被交接、门切断掌声、张总压背、沈砚摸空口袋，比台词和屏幕更电影。
3. **补强连续性。** 沈砚、张总、奖杯、三处空间、光线递进必须固定。
4. **提示词分层。** 人物/场景/风格/负面约束抽到公共层，单镜头只写变化量。

## 采纳取舍

### 采纳导演意见

- 合并/弱化屏幕说明镜头，把屏幕信息移到一个过肩镜头。
- 新增“侧门关闭，掌声被切断”的空镜。
- 张总不能反派化；“资产”台词要像行业常识。
- 庆功宴不是成功酒会，而是温柔控制现场。

### 采纳美术意见

- 补沈砚、张总的脸型、发型、体态、服装锚点。
- 明确颁奖礼、后台侧廊、高层酒店三种空间差异。
- 增加焦段、曝光、材质、色彩比例等“电影级”硬规则。
- 建议 Human 先找 moodboard，再批量生概念图。

### 采纳细分镜意见

- 保留 14 个叙事 shot_id，但总时长压到 180 秒。
- 生成层面把较长镜头拆成 4-6 秒动作单元。
- 修正奖杯连续：奖杯从舞台到后台交接，再由助理带到宴会桌。
- 宴会段固定张总在沈砚左后侧/侧前方形成控制，不跳轴。

### 采纳 Prompt Structurer 意见

- v2 文件增加公共连续性层。
- 单镜头提示词控制在 90-150 中文字左右。
- 屏幕/灯牌/奖杯刻字都避免可读文字，防止即梦生成错误中文。

## Human 下一步

建议先不要立刻批量生 14 个镜头。  
更稳的顺序：

1. Human 确认沈砚/张总人物外观方向。
2. Human 或 agent 找 3 组 moodboard：颁奖礼、后台侧廊、高层庆功宴。
3. 先生成 5 张关键概念图：TP_001、TP_003、TP_006、TP_012、TP_014。
4. 确认电影质感后，再扩展 14 个镜头图生视频。
