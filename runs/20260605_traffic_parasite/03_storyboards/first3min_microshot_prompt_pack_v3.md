# 《流量寄生虫》前3分钟 micro-shot 分镜与即梦提示词包 v3

## 这版修正什么

v2 的问题：

1. shot 时长过长，像“概念镜头”，不是图生视频可执行镜头。
2. 缺少 0-3s / 3-6s 这种微时间码调度。
3. 颁奖礼内场“粉丝灯牌海”不够真实，正式电影奖更像行业内场掌声，粉丝应援应放在场外、红毯区、直播屏或隔墙声里。
4. 提示词太像摘要，不像“给模型执行的画面指令”。

v3 改法：

- 前 3 分钟拆成 42 个 micro-shot，每个 3-6 秒。
- 每个单元都有：时间码、景别/镜头、主体动作、声音、即梦画面提示词。
- 内场改为行业观众、评委、记者摄影区；粉丝只作为场外声、直播屏、后台监看屏碎片出现。
- 台词不塞进图像 prompt，单独放在声音层。

## 公共连续性

人物与空间设定参考：`04_visual_concept/first3min_character_scene_bible_v2.md`  
声音与台词参考：`03_storyboards/first3min_sound_dialogue_layer_v1.md`

### 重要修正：粉丝应援的真实位置

本片开场按“正式电影行业奖项”处理，内场不做粉丝灯牌海。  
内场是行业观众、电影人、记者摄影区、礼仪和工作人员。  
粉丝存在于：

- 剧院外红毯围栏外的远声；
- 后台监看屏/直播屏里的场外画面；
- 社媒运营平板上的直播弹幕/应援图块；
- 沈砚离场时远处隔墙喊声。

这样既保留“公众爱意”，又避免把电影奖拍成综艺应援现场。

## 生成执行规则

1. 每个 micro-shot 单独生成 3-5 秒，不要让模型一次承担 10 秒复杂动作。
2. 人物台词全部后期配音/字幕，图像 prompt 只写可见口型和身体动作。
3. 内场不出现粉丝灯牌海；粉丝应援只通过场外声、直播屏、社媒屏幕碎片出现。
4. 屏幕、灯牌、合同、奖杯刻字都不要求可读，避免中文错误。
5. 多人宴会镜头限制 4-6 人，人物脸尽量虚焦或遮挡，降低崩脸。
6. 先生成 TP3_001、TP3_009、TP3_018、TP3_029、TP3_034、TP3_038 六个关键概念/动作镜头，再扩展全 38 个 micro-shot。
