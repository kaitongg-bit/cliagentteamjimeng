1. 我基本能顺着看懂空间变化，尤其 `侧门 -> 后台侧廊 -> 玻璃廊 -> 宴会入口 -> 服务门 -> 服务通道 -> 公关房` 这条链很清楚，属于能在脑中接上的版本。

2. 最容易小懵的是宴会区到公关房这一段：`S23-S30` 连续出现“边缘聚拢、伸手要手机、耳语、带离、进服务门、通道、门禁开房”，信息都对，但功能太密，第一次看可能会觉得是在看流程记录。

5. 奖杯链很清楚，但 `S17/S20/S22` 连着看容易有一点“为了说明机制而说明机制”。

6. 手机链的压迫感比奖杯更狠，尤其 `S11` 发现口袋空了、`S24` 伸手却拿不回、`S32` 被放到桌中央够不到`，三下很有效。
