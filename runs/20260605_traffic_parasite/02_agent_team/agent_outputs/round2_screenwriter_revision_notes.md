# 《流量寄生虫》Round 2 编剧修订说明

## 总体修订方向

本轮将原梗概从“复仇爽文式全行业清算”改为“账号人格吞掉真人的悲剧”。保留顶流沈砚被黑营销构陷、成为黑号复仇者、从受害者滑向施害者、最终付出代价的题材核心，但取消机械结构对齐和一键式证据胜利。新的132分钟梗概强调：证据永远残缺，复仇确有爽感，但爽感会污染他人，系统不会因一次曝光而终结。

## 吸收反方编剧意见

1. 吸收“删除1:1对齐《寄生虫》结构”的意见  
已在新版开头明确改为只借“寄生、阶层、空间、气味、暴露”的主题灵感，不再宣称结构对齐，也不使用外部模板式段落命名。新版结构支点改为：坠落、黑号诞生、证据商品化、主动剪辑上下文、关系拉扯、肮脏曝光、有限清算、系统换壳。

2. 吸收“堕落线要来自主动选择，而非全被胁迫”的意见  
新版中沈砚多次拥有较低伤害方案：可以和韩青谈、可以只爆品牌黑幕、可以使用林遥整理的打码证据包。但他因旧恨、账号增长、控制欲和“要更痛”的复仇欲主动选择更狠打法。这样保留受害者起点，也让施害责任更不可推卸。

3. 吸收“黑产操作不能像万能技能”的意见  
新版补入灰产中介阿舟、外包投放公司潮声、素材渠道、账号群控、投放排期、广告公司洗钱链路、平台限流和选择性放大等环节。沈砚不再单枪匹马掌握全行业真相，而是逐步成为一条链路里的关键操盘者。

4. 吸收“取证必须有失败、污染、缺口”的意见  
新版设置监控缺失、聊天截图污染、录音剪辑、档案缺页、转账洗过三层、证人不愿作证、韩青手机摔坏导致完整录屏损毁等障碍。每个证据都需要林遥、阿舟、保安、受害者等他人验证或补足，且部分证据永远无法闭环。

5. 吸收“后半段不要官方宣传片化”的意见  
新版取消“全量证据放出→全民共识→清朗行动→监狱写宣传文章”的顺滑闭环。监管介入只作为多方压力汇合后的局部结果，张总和部分营销号被处理，陆昭未被完全坐实，平台和资本切割责任、换壳重生。

6. 吸收“赎罪行为本身也可能消费受害者”的意见  
新版的午夜爆料既是最大爽点，也是最大污点：许知夏、韩青、保安儿子和无关女演员被二次伤害。沈砚最后选择把隐私材料交给律师和警方，而不是继续公开给网友审判，正是从“曝光即正义”退回到承担边界。

7. 吸收“减少流水账，增强关键场景”的意见  
新版强化旧影城对峙、地下投放公司、韩青直播维权、午夜爆料、探视室照片等场景，把人物选择和后果放进可拍的动作与关系冲突里。

## 吸收观众 agent 意见

1. 吸收“前30分钟爽感有效，应保留”的意见  
新版保留领奖台到城中村的坠落、第一期黑号反杀营销号、打击确有问题男星等入口爽点，让观众仍能先站在沈砚一边。

2. 吸收“沈砚作为影帝的能力应转化为行动优势”的意见  
新版让他的演员能力变成伪装、读人、模仿账号语气和操控舆论叙事的能力，而不是简单“改头换面潜入原公司”。

3. 吸收“中段伤害无辜者必须让观众不舒服，但还能跟”的意见  
新版将许知夏受害处理得更具体：不是立刻抑郁住院的强情节标签，而是直播失语、空麦被二创、代言撤掉、复工失败，减少工具化，同时让伤害持续存在。

4. 吸收“60-90分钟最有戏，要强化人物关系”的意见  
新版大幅扩写林遥。她不再是善意提醒器，而是老粉、证据整理者、被粉圈伤害的人、沈砚的临时合作者和最终拒绝者。她帮助验证证据，但坚持打码、征得当事人同意和保护普通人，由此与沈砚产生真正价值冲突。

5. 吸收“老粉不能轻易原谅”的意见  
新版结尾林遥探视时明确不原谅沈砚，也不再为他服务。她继续整理时间线“不是为了你”，把关系落点从救赎改为独立见证。

6. 吸收“90-132分钟应保留清算满足，但压住说教”的意见  
新版保留午夜连环爆料带来的类型爽感：张总被围堵、陆昭活动中断、潮声搬硬盘、营销号互咬。但随即让爽感变脏，并取消宣传文章、主题金句和温暖阳光收束。

7. 吸收“结尾应有复杂余味”的意见  
新版结尾呈现受害者后续、平台专题下线、新账号继续消费沈砚、直播基地招商、证据缺失文档等画面，形成系统未终结的余味。

## 未吸收的意见及原因

1. 未完全保留“大粉持刀冲公司”的具体事件  
原因：该事件冲击力强，但容易把韩青塑造成外部暴力触发工具，也会让舆论焦点从沈砚制造的日常网暴伤害转向突发刑案。新版改为韩青在张总公司楼下直播维权、砸碎玻璃受伤被带走，仍保留“他的恶长出现实后果”的爆点，同时更贴近网暴受害者被再次叙事化的主题。

2. 未保留“烧合同”作为80-90分钟英雄动作  
原因：观众认为烧合同有记忆点，但也指出可能太英雄化。新版改为沈砚没有烧掉合同，而是把合同放进抽屉并承认自己动摇，让角色更危险、更复杂。最终拒绝资本包装不靠漂亮姿态，而靠后续投案和停止公开隐私材料完成。

3. 未保留“全量曝光后自己也被审判”的完整爽文形态  
原因：观众喜欢这个动作的满足感，因此新版保留“公开自己身份和罪证”的关键选择；但不保留全量行业证据和全民共识，因为反方指出这会削弱悲剧和可信度。新版让他只撕开一角，并承认自己掌握的材料也有污染。

4. 未保留“老粉带反网暴书探监”的道具  
原因：该道具有清晰情绪，但与“宣传材料、警示文章”的说教风险相近。新版改为林遥带来旧影城变直播基地的照片，更能呈现系统换壳和关系冷却。

5. 未吸收“前30分钟维持高密度连续升级”的节奏  
原因：前30分钟抓人这一点保留，但新版放慢买号、核证和第一次发布过程，避免黑号成长像短视频外挂。牺牲部分速度，换取可信度和后续因果。

6. 未将结尾写成明确刑期和道德定论  
原因：原版12年、种花、读书、文章金句能提供确定性，但会把复杂悲剧收成规训化结论。新版只通过起诉罪名、新闻字幕和庭审片段呈现法律后果，把最终判断留在人物关系和受害者余波里。

## 本轮最大改动

新版把“沈砚用一包证据炸翻全行业并完成赎罪”改为“沈砚用一次肮脏曝光短暂赢回清白，却二次伤害他人，最后只能承担自己那部分罪，眼看系统换壳继续寄生”。
