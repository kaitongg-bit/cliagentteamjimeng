# 《皮下清算》Round 2 编剧改写吸收说明

## 来自反方编剧的意见：已吸收

1. **中段缺少真正改变方向的反转**

已吸收。新版在50-110分钟加入三次方向改变：50-60分钟女主只能拿到低层证据且被陆青认出；70-80分钟中点发现黑营销公司只是外包层，真正源头是经纪体系、竞品团队、平台商业方的合流；90-100分钟敌方喂给她假证据，迫使她不能简单按下“全网曝光”按钮。

2. **女主道德弧线太平，容易变成爽文猎手**

已吸收。新版让林静衣为了套证据参与苏禾项目，间接造成苏禾被围堵、停工、住院。她不再只是使用敌人工具惩罚坏人，而是切实伤害了一个无辜者，并在100-110分钟被舆论反咬为“雇水军黑苏禾”的共犯。

3. **黑营销公司和证据收集过于便利**

已吸收。新版将证据链改成多方拼图：低层话术库、排期表、账号矩阵来自外包公司；甲方回批来自参与项目；付款路径来自欠款写手和陆青；偷拍视频源头和平台记录需要沈澜、律师、审核人员协助核验。删除了“新人复制全部合同、流水、私人网盘密码”的万能设定。

4. **公开清算过于顺滑，缺少法律、平台和舆论反噬**

已吸收。新版中，第一次调查稿被限流，第二次被投诉下架，证据被质疑为AI伪造或炒作复出。真正推进清算的是调查记者、律师、警方、行业协会、法院立案材料和公开听证，而不是热搜自动完成正义。

5. **结尾的网暴循环没有落到剧情后果**

已吸收。新版让循环在清算过程中反咬女主：网友人肉普通员工和实习生，营销号把她包装成“复仇女王”继续变现，苏禾粉丝攻击她，她也被旧粉和路人重新审判。结尾用平台热词池生成新爆料标题的画面收束，不再靠角色台词点题。

6. **反派过黑，系统过薄**

已吸收。新版增加陆青作为灰度中层：他知道不对，但被欠款、KPI和甲方压住，既利用女主也帮助女主。周峻、徐漫、阿凯仍是共犯，但重点从单个恶人扩大到系统化流程。

7. **女主伪装过轻**

已吸收。新版不让她剪发后直接进入核心公司，而是从三块一条的洗稿群、兼职任务、线下结算逐步进入外包公司，且在潜入后很快被陆青认出，身份始终是危险点。

8. **女主“清白”太绝对**

已吸收。新版开场明确她曾默认团队做过热搜包装和轻度拉踩，后来发现自己团队也采购过类似“口碑维护”服务。她不是圣女复仇，而是曾经受益于系统、后来被系统吞掉的人。

## 来自观众 agent 的意见：已吸收

1. **前30分钟抓人，但需要更明确的冤案钩子和幕后一闪**

已吸收。新版保留领奖、发布会大屏爆录音、解约撤物料的强入口，同时在0-10分钟加入周峻临时改路线和偷拍车窗，在10-20分钟让周峻侧台不救场，给观众更早的“有人做局”信号。

2. **50-110分钟电脑后台动作容易疲劳**

已吸收。新版中段加入线下结算、楼梯间身份威胁、医院走廊、会议室甲方出现、出租屋被翻、公开听证等更可拍的动作场面，减少单纯看热搜、复制文件、操控后台的重复感。

3. **复仇爽感成立，但缺少正面对抗和危险升级**

已吸收。新版保留清算快感，但增加周峻到黑营销公司“风控”的正面压迫、陆青与林静衣的楼梯间摊牌、阿凯清查设备、沈澜质疑假证据、听证现场问询等对抗节点。

4. **女性观众会在意女主是否伤害无辜者**

已吸收。新版把苏禾作为明确无辜受害者放入中段，并让林静衣付出道歉、被反噬、放弃煽动性材料的代价。她的狠有边界，而且边界是被痛苦教育出来的。

5. **结尾金句和街头新瓜偏说教**

已吸收。新版删除“黑过你的地方，别再自己站进去”式金句，不让女主发表宣言。结尾通过删掉复仇剪辑、保留调查链接和道歉、热词池刷新、新爆料标题生成来表达循环。

6. **最有记忆点的发布会画面应保留**

已吸收。新版保留并强化发布会大屏播放剪辑录音、记者话筒逼近、弹幕围攻、设备故障切断完整解释的场面。

7. **“男主的不舒服”无法理解**

部分吸收。新版没有硬加传统男主，因为原题材核心是女明星、黑营销公司、网暴循环；但增加陆青作为稳定关系压力角色，承担旁观、共犯、愧疚和利益自保的复杂位置，用来增强中段关系戏。

## 没有吸收的意见及原因

1. **没有把结尾改成完全的司法胜利**

原因：项目要求保留“最终清算黑产与共犯，并落回网暴循环的反讽”。因此新版只让司法和调查程序启动，让部分共犯被问询、账号矩阵被封、行业调查展开，不写成所有坏人彻底伏法的大团圆。这样既有清算行动，也保留系统未被根除的余味。

2. **没有完全取消公开传播和热搜元素**

原因：题材核心就是黑营销、热搜和网暴循环，完全转向纯法庭片会削弱类型入口。新版保留热搜和传播，但不再让热搜承担正义裁判功能，而是让它成为噪音、反噬和被利用的场域。

3. **没有把林静衣写成彻底拒绝复仇的人**

原因：原题材需要“伪装进入黑营销公司，最终清算黑产与共犯”。如果让她完全放弃复仇，类型承诺会落空。新版处理为：她仍然清算，但放弃无差别网暴式清算，改走可验证证据和调查程序。

4. **没有增加大量完整台词或具体场景对白**

原因：本轮任务明确要求交付“更强的长片剧情梗概/分段大纲”，不是完整台词剧本。因此新版只写可拍动作、关系转折和段落功能，避免展开成完整剧本。
